## Deferred / Documented Limitations

These are deliberately not closed in this session. They are recorded here so they do not get
silently forgotten:

- **MacMini SSH password rotation** (Task 4). DEFERRED at Paul's explicit request on 2026-10-09
  ("ignore that for now"). Not a blocker. The credential remains in git history at `5d7b2ec`. Do
  not re-raise unless Paul does.
- **Event hooks on Windows** (Task 8). PRODUCT defect, not a test defect. `hookScripts` filters
  on `stat.mode & 0o111`; NTFS has no exec bit, so the filter matches nothing. Pinned by
  `electron/events/sources.test.ts`. Fix requires a product decision about how Windows invokes a
  hook. Recorded in `docs/WINDOWS-PORT.md` Risks.
- **Audio default-device switching on Windows**. Deliberately NOT supported. Windows exposes no
  public API for choosing the default endpoint; the private `IPolicyConfig` contract is
  unreliable. The protocol returns `not_supported` for `audio.default`; the Electron wrapper
  raises `HostNotSupported` with a message that points users to Windows Sound settings. This is
  the test case `refuses to change the Windows audio default device and names the only supported
  alternative`.
- **Bluetooth device enumeration**. The helper currently reports radios (adapters) only, not
  paired devices. `windowsBluetoothStatus` synthesises a `powered: available` device list of
  `paired: false, connected: false` entries so the panel renders. Real device enumeration would
  need a Windows-specific surface (e.g. `Windows.Devices.Bluetooth` UWP API or a paired-devices
  registry scan) and is a candidate for a follow-up milestone.

## Critical Anti-Patterns to Keep Holding

| Pattern | Prevention |
|---------|------------|
| Recording "green" from a prior session after new code lands | Fresh `git status --porcelain` + `npm test` before any green claim. |
| A blanket `process.platform === 'win32'` skip | Capability probe via `apps/desktop/electron/test-support/capabilities.ts`. |
| Weakening a security assertion to get green | The package-io symlink test is unchanged; gated, not weakened, with an everywhere-runnable companion. |
| Silently netting the assertion count down | When count changes, update every doc citing the old number. |
| Hard-coding the helper's executable path or accepting a PATH lookup | `windowsControlsExecutable` only resolves `resourcesPath/windows-controls/Herald.WindowsControls.exe` or `cwd/build/windows-controls/Herald.WindowsControls.exe`. No PATH, no env override. |
| A Wi-Fi password on a command line | `parseWifiInterface` + `required('netsh', ...)` keep the SSID in one argv item; `password` on a connect action is rejected. |
| A `powercfg` GUID outside the allowlist | `POWER_SCHEMES` is the only source; `windowsControlAction` throws on unknown profile. |
