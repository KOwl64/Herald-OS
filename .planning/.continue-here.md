# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [x] CONSTRAINT: settings.local.json overrides settings.json — when changing ANTHROPIC_MODEL or any env var on MacMini, update BOTH files. Editing only settings.json is silently overridden.
- [x] CONSTRAINT: Long-running Claude Code daemons cache old config in memory. After changing settings, find and kill any `claude` process older than the change. On MacMini the daemon was 5 days old (PID 72864).
- [x] CONSTRAINT: The model picker shows Anthropic's catalog (Default/Opus/Fable/Sonnet/Haiku) regardless of the active API key. With a minimax key, only the minimax custom model (option 6) is reachable. Options 1-5 will fail with auth errors if selected.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Edit only settings.json | Silently overridden by settings.local.json. Banner still shows old model. | blocking | Always diff both files after an env change. |
| Skip killing the daemon | Stale config persists in memory; restart alone doesn't refresh it. | blocking | `pgrep -f claude` and `kill` any process older than the last settings change before declaring the fix done. |
| Treat the model picker as a real menu | Options 1-5 are placeholders from Claude Code's hard-coded catalog. They don't reflect which models the active API key can reach. | advisory | After changing the API key/endpoint, verify a real model call works via curl before trusting the picker. |
